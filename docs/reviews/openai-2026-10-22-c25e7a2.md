- Severity: minor
  File: lib/redmine_subtask/subtask_listener.rb:44
  Problem: Double-escaping user-facing text. The tracker names are pre-escaped with ERB::Util.html_escape before being interpolated into the translation, and Redmine’s flash rendering (via content_tag) escapes again. This will display HTML entities literally for tracker names containing characters like “&” (e.g., “R&D” becomes “R&amp;D” in the UI).
  Failure scenario: An admin creates a tracker named “R&D”. A user edits an issue, ticks a rule that would duplicate an existing subtask. The warning flash shows “Not created again, the issue already has this subtask: R&amp;D” instead of “R&D”.
  Fix: Remove the explicit escaping. Let the view layer escape once:
  controller.flash[:warning] = l(:warning_subtask_exists, trackers: names.join(', '))
  Resolution: not changed, refuted. Redmine's `render_flash_messages` (app/helpers/application_helper.rb:527 on 7.0-stable-GEOxyz) renders `v.html_safe`, it does not escape again. Without the explicit escape a tracker name with `<` would be HTML; with it "R&D" shows as "R&D". Same as the plugin's existing error flash, whose test (`test_failure_to_create_a_subtask_is_shown_to_the_user`) shows `<b>` as text.

- Severity: minor
  File: lib/redmine_subtask/subtask_listener.rb:42-44
  Problem: N+1 queries for tracker names. For each duplicate rule, the code performs a Tracker.find_by, resulting in as many queries as duplicates.
  Failure scenario: A project defines many rules for different trackers; an editor ticks all of them on an issue that already has matching children. The warning is generated, but the action fires one SELECT per duplicate tracker, needlessly increasing DB load.
  Fix: Fetch names in a single query:
  ids = duplicates.map(&:child).uniq
  names_by_id = Tracker.where(id: ids).pluck(:id, :name).to_h
  names = duplicates.map { |s| names_by_id[s.child] }.compact.uniq
  Resolution: not changed. `duplicates` holds the rules ticked again on one issue, in practice one or two; a query per rule costs less than the extra code.
